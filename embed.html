ゲーム組み込みガイド

キャラシートは1体ずつ分割して呼び出せます。自作ゲーム・ノベルツール・Botなどへの取り込み方法は次の4通り。

1. キャラシート単体ページ（リンク / iframe）

各キャラは sheet.html?no=番号（または ?name=名前）で独立ページとして開けます。iframeでそのまま埋め込み可能。

<iframe src="sheet.html?no=019" width="100%" height="420"></iframe>
▼ 実際の表示（Rei のシート）

2. Web Component（<cn-sheet>）

HTMLタグ1つでシートを部品として差し込めます。compact 属性で小型版になります。

<script type="module" src="js/cn-sheet.js"></script>
<cn-sheet no="001"></cn-sheet>
<cn-sheet no="002" compact></cn-sheet>
▼ 実際の表示（通常 / compact）

3. JavaScript API（js/cn-data.js）

ゲームロジックからデータだけ使う場合。ESモジュールとして読み込みます。

import { loadCharacters, getCharacter, listCharacters, imageDir }
  from './js/cn-data.js';

const jin  = await getCharacter('001');     // 番号・名前・スラッグで検索
const fuma = await listCharacters({ clan: 'Fuma' });  // クランで絞り込み
const img  = imageDir(jin) + 'main.png';    // 画像パス

// 例: ランダムに敵キャラを選ぶ
const all = (await loadCharacters()).characters;
const enemy = all[Math.floor(Math.random() * all.length)];
▼ 動作デモ：クリックでランダムに1体引く

4. 生データ（JSON）

言語を問わず使えます。data/characters.json を直接読むか、各キャラシートの「JSONダウンロード」で1体分だけ取り出せます。

fetch('data/characters.json')
  .then(r => r.json())
  .then(d => console.log(d.characters.length)); // 38

1キャラのフィールド: no / name / clan / ninjutsu / weapon / birthday / setting / genre / relationships[] / prompts{chibi…isekai}

画像の解決ルール

キャラ画像は images/characters/<番号>_<スラッグ>/ に置きます。main.png がシートの顔画像、01.png〜12.png がギャラリーに使われます。imageDir(c) がこのフォルダのURLを返すので、ゲーム側でスプライトとして読むこともできます。
